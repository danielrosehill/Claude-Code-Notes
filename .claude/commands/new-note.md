Create a new note for the Claude Code Notes repository.

The user will provide a source — this could be:
- A path to a repository that demonstrates a pattern or technique
- A path to a voice note / audio file (transcribe it first)
- A URL to a repo or resource
- A description of a pattern or discovery

## Instructions

1. **Understand the source**: Read the provided repo, transcribe the audio, or fetch the URL to understand the pattern/discovery being documented.

2. **Create the note** in `notes/` as a markdown file:
   - Use a kebab-case filename that captures the topic (e.g., `split-claude-md-pattern.md`)
   - Start with a clear `# Title`
   - Include the date on the second line in DD-MM-YYYY format
   - Write in Daniel's casual, opinionated voice — these are personal cliff notes, not formal docs
   - Include practical takeaways and concrete examples
   - Add disclaimers where the approach is subjective or may not suit everyone
   - Link to source repos/resources where relevant
   - Note that Claude Code moves fast and this may become outdated

3. **Update the README index**: Add a row to the Notes Index table in README.md with:
   - Link to the note file
   - Date in DD/MM/YYYY format
   - One-line summary

4. **Show the user** the draft note content before committing.
