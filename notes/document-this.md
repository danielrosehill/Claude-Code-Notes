# Claude Document This (Fix Documentation Plugin)

**Date:** 06/04/2026

A Claude Code plugin for capturing system administration fixes and changes and writing them up to Notion, Obsidian, or email. Provides per-platform commands plus an orchestrator agent that picks the right destination based on user preference.

Built around the idea that terminal solutions are worth keeping — not just for yourself, but for the next person (or agent) who hits the same problem.

**Repo:** https://github.com/danielrosehill/Claude-Document-This
