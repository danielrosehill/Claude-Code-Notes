# Claude Slash Commands

**Date:** 06/04/2026

An index repo for 350+ custom slash commands across categories like development, documentation, security, and sysadmin. Acts as the umbrella over standalone slash command repos and ships automation scripts and git hooks for keeping them in sync across projects.

Useful as a browse-able catalogue when you want to lift a command into your own setup rather than reinvent it.

**Repo:** https://github.com/danielrosehill/Claude-Slash-Commands
