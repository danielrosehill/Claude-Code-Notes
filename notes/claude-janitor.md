# Claude Janitor

**Date:** 06/04/2026

A Claude Code plugin for tidying up repositories from Claude-related artefacts — stray context files, leftover scaffolding, plan/handover detritus, and other things that accumulate over a long agentic session.

Useful before publishing a repo or handing it off to humans who don't need to see the agent's working notes.

**Repo:** https://github.com/danielrosehill/Claude-Janitor
