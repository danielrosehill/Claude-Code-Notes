# New Turn Claude Hook

**Date:** 06/04/2026

A planning-stage concept for a Claude Code hook that automatically decides whether the user should start a fresh conversation or continue the current one. The idea is to use lightweight logic to fight context bloat — once a conversation is doing more harm than good to performance, the hook nudges (or forces) a reset.

Currently exploratory, gated on what the hooks API actually exposes.

**Repo:** https://github.com/danielrosehill/New-Turn-Claude-Hook
