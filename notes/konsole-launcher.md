# Claude Konsole Launcher

**Date:** 06/04/2026

A WIP launch utility for spinning up Claude Code inside Konsole on KDE Plasma. The point is to make starting a session feel like opening any other desktop app rather than a terminal ritual — pick a project, click, and you land in Claude Code in the right working directory.

**Repo:** https://github.com/danielrosehill/Claude-Konsole-Launcher
