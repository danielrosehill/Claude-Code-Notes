# Claude Linux Desktop Manager

**Date:** 06/04/2026

A GUI wrapper around Claude Code that exposes system administration tasks — configuration, benchmarking, security audits — as buttons backed by slash commands. The pitch is that Linux power-user tools shouldn't require remembering every CLI flag when an agent can drive them for you.

A nice example of treating Claude Code as an execution backend for a higher-level interface.

**Repo:** https://github.com/danielrosehill/Claude-Linux-Desktop-Manager
