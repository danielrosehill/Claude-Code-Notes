# Claude Repo Creator

**Date:** 06/04/2026

A Claude Code workspace for generating GitHub repos from natural-language descriptions. Handles the whole flow — local folder, git init, remote creation via `gh`, and optional scaffolding (CLAUDE.md, slash commands). Driven by `/onboard` for first-time setup and `/new-repo` for each new project.

Reduces "I have an idea" to "the repo exists and is cloned" to one command.

**Repo:** https://github.com/danielrosehill/Claude-Repo-Creator
