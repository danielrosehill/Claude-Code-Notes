# Claude Model Identifier

**Date:** 06/04/2026

A small prompt template that asks Claude to identify which model is actually serving the session — usable as a `CLAUDE.md` snippet or as a slash command. A sanity check for when you suspect the harness has silently routed you to a different model than the one you selected.

A workaround rather than a fix — but a useful one given how often model identity becomes load-bearing.

**Repo:** https://github.com/danielrosehill/Claude-Model-Identifier
