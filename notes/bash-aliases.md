# Claude Code Bash Aliases

**Date:** 06/04/2026

A curated collection of bash aliases for working with Claude Code on Linux. Provides shortcuts for navigating config directories, scaffolding slash commands and agents, and managing MCP servers. Maintained in `~/.bash_aliases` and version-controlled with YADM.

A small QoL layer — none of it is magic, but the convenience of `cdcc` over typing `cd ~/.claude` adds up over a day of fiddling.

**Repo:** https://github.com/danielrosehill/Claude-Code-Bash-Aliases
