# Claude Deep Research Template

**Date:** 06/04/2026

A workspace template for running structured research projects in Claude Code. Splits work across phases — context gathering, prompt planning, research execution, and synthesis — with persistent documentation between phases so iterations build on prior work rather than restarting.

Scales from quick lookups up to longer multi-session studies (academic, market, technical, strategic). It's an example of using a repo as a workspace rather than as code.

**Repo:** https://github.com/danielrosehill/Claude-Deep-Research-Template
