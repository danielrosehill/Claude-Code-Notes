# Claude Spec Starter

**Date:** 06/04/2026

A template that turns a free-form project description into structured specs and context files via slash commands. Parses an initial prompt into a technical spec, contextual notes, and project docs, then lets you iterate on each over time.

Designed with voice-driven development in mind — you ramble at it, it organises the rambling.

**Repo:** https://github.com/danielrosehill/Claude-Spec-Starter
