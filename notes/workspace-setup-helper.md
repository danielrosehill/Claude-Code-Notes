# Claude Workspace Setup Helper

**Date:** 06/04/2026

An interactive setup tool for spinning up Claude Workspaces — pre-configured repository templates aimed at specific use cases. Reads a catalogue of available workspaces, walks the user through selection by objective, and clones the chosen template locally.

Pairs naturally with the Agent Workspace Model: instead of hand-rolling a workspace each time, pick one off the shelf.

**Repo:** https://github.com/danielrosehill/Claude-Workspace-Setup-Helper
